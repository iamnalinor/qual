# Попробовать Qual

Установите бинарный файл по [инструкции в README](../README.md#установка), затем настройте приложение:

```sh
qual init
```

Выберите провайдера, подключите учётную запись или введите API-ключ, выберите модели и подтвердите настройки. Все подключения и модели настраиваются через `init`.

Запустите проверку небольшого реального PR:

```sh
qual review https://github.com/cli/cli/pull/15044
```

Это закрытый PR GitHub CLI с изменениями в двух файлах. Qual сам загрузит исходники. Во время проверки видны действия ревьюера и ведущего; `Ctrl+O` открывает подробности. Длительность зависит от модели и сети.

После завершения появятся итог проверки, путь к отчёту и команда просмотра сессии. Чтобы также сохранить `report.md` и `report.json` в каталог `./review`, добавьте к команде ревью `--output ./review`.

При необходимости нажмите `Ctrl+C`: Qual сохранит сессию и выведет команду продолжения. Её также можно найти так:

```sh
qual sessions list
qual sessions resume SESSION_ID
```
